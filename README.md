# Trading Journal Pro

A professional forex trading journal with cloud sync powered by Supabase.

## Features

- 📊 Dashboard with key metrics (drawdown, progress, win rate)
- 📈 Equity curve and trade outcome charts
- 📅 Calendar view with daily/weekly P&L summaries
- 🎯 Journal score radar chart
- ☁️ Real-time cloud sync with Supabase
- 📱 Access from anywhere

## Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the app:**
   ```bash
   npm start
   ```

3. **Open in browser:**
   The app will open at [http://localhost:3000](http://localhost:3000)

## Your Supabase is already configured!

The app is pre-configured with your Supabase credentials. Just run it and start adding trades!

## Usage

- **Dashboard Tab**: View all your metrics, charts, and calendar
- **All Trades Tab**: View, add, edit, and delete trades
- **Add Trade**: Click the blue "Add Trade" button
- **Update Trade**: Click the edit icon to close trades and record P&L
- **Sync**: Click the sync button to manually refresh data

## Tech Stack

- React 18
- Supabase (PostgreSQL + Real-time)
- Recharts (Charts)
- Lucide React (Icons)
- Tailwind CSS (Styling)
